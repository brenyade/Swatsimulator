MAP FORMAT

grid: array of equal-length row strings. # wall, . floor, D door.

playerStart: {tx, ty} tile coords (required).

Optional arrays (all entries are {tx, ty, ...}): teammates, suspects (armed, willSurrender 0-1, name, elite, patrol), hostages, civilians (wanderRadius), evidence.

Also optional: name, briefing, timeLimit (seconds), loadout {lethal, nonlethal}, objectives (auto-generated if omitted).

Every spawn point must sit on a floor tile and be reachable from playerStart — the validator checks both before letting you deploy, and NPCs get the same AI as every built-in mission automatically once the map loads.
